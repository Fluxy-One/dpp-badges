# DPP Ready & DPP Verified Badges by Fluxy.One

Official branding assets and integration guidelines for **Digital Product Passport (DPP)** badges by Fluxy.One. These assets allow authorized partners to visually present compliance and platform integration.

---

## 📦 Asset Structure

*   **/badge** — Horizontal layouts designed for system footers, tables, and compact interfaces (32px and 64px heights).
*   **/icon** — Hexagonal badges featuring the official EU ESPR regulatory reference (`EU Reg. 2024/1781`), optimized for product specification pages and sustainability dashboards.

*Note: For crisp rendering on Retina and High-DPI displays, we highly recommend using the vector **SVG** files.*
